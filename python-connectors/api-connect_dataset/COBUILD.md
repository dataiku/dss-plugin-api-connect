- Use this dataset when the API is a direct data source with no row-dependent parameters: typically a fixed endpoint and a tabular result for simple ingestion or scheduled refresh, with minimal Flow logic.
- Use the API Connect recipe when requests depend on an existing dataset, such as `/customers/{{customer_id}}` for each customer. The recipe triggers a request for each input row; this dataset needs no driver rows.
- Set `endpoint_url` and `http_method` from the API contract. Query parameters and headers use `endpoint_query_string` and `endpoint_headers`; a raw body uses `body_format="RAW"` and `text_body`.
- `auth_type=null` supports either no authentication (`credential` unset) or a generic credential preset. A secure authentication type requires its corresponding visible preset.
- API Connect automatically injects an API-key preset into the header or query parameter configured by the user in that preset. Do not add the API key again to request fields.
- Leave `extraction_key` unset for a root JSON array; otherwise use its dot-separated object path, such as `data.items`.
- Set `raw_output=false` to expose record fields as columns; nested objects and arrays remain JSON strings. Keep `raw_output=true` to preserve each selected response item as JSON.
- Select `pagination_type` from the API documentation; do not infer it from the endpoint shape. For `next_page`, set `next_page_url_key` when the URL is in the response body; otherwise pagination uses the HTTP `Link` header. Relative body-provided URLs also require `is_next_page_url_relative=true` and `next_page_url_base`. Offset and page pagination require `skip_key`; set `extraction_key` only for nested records. Cursor pagination requires `cursor_next_token_path` and `cursor_query_param`, with optional `cursor_initial_token`.
- This dataset is read-only and cannot be a recipe output. Saving configuration does not call the API; previewing, testing, schema inference, and reading execute the configured request. Do not automatically test or retry potentially mutating requests unless the user's request authorizes that operation.
